Why Choose BatxRinth?

Designed for players and developers who demand total control and privacy.

🛡️

100% Ad-Free Interface

No sponsored placements, paid recommendations, ad webviews, or affiliate cookies. Clean performance without distractions.

🔒

Privacy by Default

Zero background analytics, tracking pixels, device fingerprinting, or crash-report uploads. Your data stays on your machine.

🔑

Official Microsoft Auth

Secure PKCE system-browser OAuth authorization directly with Microsoft endpoints. Secrets are encrypted and never logged.

💻

Offline Local Testing Profiles

Built-in support for offline testing profiles with username sanitization, designed for local development and offline servers.

⚡

High-Performance Core

Lightweight Rust core backend for fast startup times, low RAM usage, and instant modpack library resolution.

👾

Discord Rich Presence

Optional game status integration with granular privacy controls. Show instance name, play time, or hide private worlds.

Network Activity Transparency

BatxRinth only makes explicit, user-initiated outbound requests required for normal launcher operation:

  • Game Metadata & Mods: Modrinth API and CDN downloads.
  • Official Game Jars & Assets: Mojang and Minecraft asset servers.
  • Mod Loader Manifests: Fabric, Forge, NeoForge, and Quilt metadata.
  • Microsoft Authentication: Official Microsoft OAuth 2.0 endpoints.
  • Updates: Direct release checks via GitHub Releases.
